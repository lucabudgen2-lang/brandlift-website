## 1. `/diensten/website-laten-maken`

### Page Purpose

Commercial pillar page for companies looking for a professional, strategic website.

This page should position Brandlift as a website partner that combines strategy, design, local SEO and conversion, not as a generic website builder.

### Search Intent

Commercial. The searcher is comparing website builders, agencies or freelancers and wants to understand whether Brandlift can build the right website for their business.

### Target Audience

Dutch MKB companies and service businesses that need a professional website to generate more visibility, trust and requests.

### Keyword Map

Primary keyword:

- `website laten maken`

Secondary keywords:

- `website laten bouwen`
- `professionele website laten maken`
- `maatwerk website laten maken`
- `maatwerk website`
- `website op maat`
- `zakelijke website laten maken`
- `nieuwe website laten maken`
- `website op maat laten maken`

### Core Promise

Brandlift bouwt websites die niet alleen mooi ogen, maar ook duidelijk maken waarom klanten voor jouw bedrijf moeten kiezen.
