## The prompt (reusable page-plan generator)

```
ROLE: SEO content strategist for Brandlift, a Den Haag web agency building
strategische websites met lokale SEO en conversie for Dutch vakbedrijven.

INPUTS:
- DataForSEO research: docs/dfs-track1-findings.md (keywords/clusters/volume caveat),
  dfs-track2-competitors.md (who ranks + why), dfs-track3-why.md (authority/on-page),
  dfs-keywords-commercial.csv (181 kw: vol/KD/cpc/refdomains/intent).
- Page inventory + phasing: docs/sitemap-and-page-plan-v1.md.
- Brand/voice: PROJECT-BRIEF.md §3.

TASK: For EVERY page in the inventory, output a page plan with exactly these fields:
  1. Meta line: URL · type · phase · status
  2. Primary target KW (recent vol, KD, intent) + 2-5 secondary/semantic KWs
  3. Topic & angle - the specific take, and how it beats the ranking competitor
     for this SERP (cite Track 2/3: e.g. flerque shows prices, dewerkendewebsite's
     cost page is weak at #22-27).
  4. Goal - primary conversion action, secondary action, and the search intent to satisfy.
  5. H-structure - the exact H1 (must echo the primary KW naturally), ordered H2s,
     and key H3s where a section needs them.
  6. Internal links - up (to pillar/hub), down (to children), and to the conversion
     assets (cost guide, calculator, relevant case). Hub-and-spoke, purposeful only.
  7. Schema type(s).
  8. Proof/assets needed - REAL only (3 Google reviews, real cases/metrics). Flag any
     data/asset gap for Luca.
  9. Word-count target + build priority.

RULES (non-negotiable):
- Voice: Dutch, nuchter-vakman, no hype, no exclamation marks, plain hyphens '-' only
  (never em/en dashes). "wij/we" throughout; "ik" ONLY in the founder's signed quote.
- Real proof only - never fabricate reviews, metrics, or client names. AggregateRating
  only where the 3 real reviews justify it; more reviews are Luca's job.
- Strategy from the research: the cost cluster + examples win on content quality alone
  (no local-pack/authority gate); city pages are gated by reviews (build-ready, rank later).
- Add a "vanaf" price indication where it aids trust/qualification (Track 3: winners show prices).
- One page per intent - no cannibalizing filter/near-duplicate pages.
- Group output by phase (P1 -> P2 -> P3). DONE pages get a one-line "as-built" note, not a full plan.
```

## B1 · Cost guide - `/kennisbank/wat-kost-een-website-laten-maken`
*KB article · P1 · STUB → highest build priority*

- **Primary KW:** wat kost een website laten maken (367, KD 3, comm). **Secondary:** kosten website laten maken (517, KD 4) · website laten maken prijs/prijzen (140, KD 6) · hoeveel kost het om een website te laten maken (117, KD 1) · professionele website laten maken kosten (90, KD 10). **Cluster ~3,770/mo.**
- **Topic & angle:** the honest, complete answer to "what does a website cost" - price ranges by type (eenvoudig/vakbedrijf/maatwerk/webshop), what actually drives the price, and what you get at each level. **Beats the field because:** the incumbents are thin content sites and dewerkendewebsite's own cost page ranks only #22-27; a genuinely better, more transparent guide + our calculator wins a SERP that has NO local-pack gate.
- **Goal:** primary → start the calculator (B2) / plan a groeigesprek; secondary → read the stappenplan; intent → informational-commercial (researching before buying).
- **H-structure:**
  - H1: Wat kost een website laten maken? Eerlijke prijzen en keuzes uitgelegd

  - H2: Prijzen per type website *(H3: eenvoudige website · website voor vakbedrijven · maatwerk website · webshop)*

  - H2: Eenmalige kosten versus doorlopende kosten *(hosting, onderhoud, domein)*
  - H2: Zelf maken, laten maken of een goedkope aanbieder? *(honest trade-off)*
  - H2: Bereken direct wat jouw website kost *(CTA → calculator)*
  - H2: Veelgestelde vragen over de kosten *(FAQ)*

- **Schema:** Article + FAQPage (+ optional HowTo for "hoe bepaal je je budget").
- **Proof/assets:** real "vanaf" price bands (need Luca to confirm actual entry prices) · Eykelenboom case as ROI proof.
- **Length/priority:** 1,400-1,800 words · **build first.**
